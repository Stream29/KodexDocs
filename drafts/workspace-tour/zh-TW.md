# 工作台：工作階段、雙側欄與歷史定位（草稿）

> 本稿是產品說明書素材，不是已確認的網站目錄。介面名稱和操作以真實 CLI 為準；沒有錄到或沒有執行的狀態，不會用空面板代替。

## 先認識工作台

工作台頂部是工作階段標籤。左右兩側是**獨立的側欄**：兩側分別保存展開/收合、釘住狀態與寬度，內容也可以個別選擇。中間區域仍是目前的工作階段，不會因為開啟側欄而切換工作階段。

新的隔離 Home 沒有選取 Agent 時，History index 和 Terminal sessions 可能是空的。這只表示目前沒有可顯示的資料，不代表功能不可用。

## 側欄的展開、釘住與寬度

1. 將指標移到左側或右側的收合按鈕，側欄會展開，讓你先查看標題和內容。
2. 點擊按鈕即可釘住該側；移開指標後，已釘住的側欄仍會保持展開。
3. 兩側分開操作：釘住左側不會自動釘住右側，右側也不會改變左側狀態。
4. 拖動展開側欄與中央內容之間的分隔線來調整該側寬度；放開指標後，寬度會寫入設定。兩側同時展開時，應用程式會為中央內容保留空間。

本次錄製使用 120×36 終端：左側由預設 28 欄拖到 38 欄，接著檢查隔離 Home 的 `settings.yml`，確認 `sidebars.left_width: 38`。座標只屬於這次錄製尺寸，不應寫成固定快捷鍵。

## 選擇側欄內容

點擊側欄標題開啟內容選單。每一側都可以獨立選擇：

- **None**：保留側欄標題和控制，不顯示正文。
- **Terminal sessions**：顯示目前選取 Agent 持有的活動終端程序。
- **History index**：顯示目前選取 Agent 的稀疏歷史索引時間線。

因此不要把側欄寫成固定的「工作階段目錄」。選擇 None 後，空白正文是明確的設定結果；選擇其他項目後，是否有資料列仍取決於目前工作階段狀態。

## History index：預覽與定位

有歷史項目時：

1. 將指標停在項目上，等待預覽出現。預覽會讀取完整項目內容；問答項目使用唯讀的歷史表單樣式。
2. 在項目上開啟右鍵選單，可以看到項目索引和 **Check out**。
3. 選擇 **Check out** 只會把目前的歷史閱讀位置定位到該項目，然後關閉選單；不會回退對話、不會重寫歷史，也不會執行 Git checkout。

本批錄製沒有偽造歷史項目。隔離空 Home 沒有選取 Agent，不能安全地宣稱已完成預覽或 Check out 的線上示範；請參考 `scenes.md` 的阻塞記錄。

## Terminal sessions：查看與關閉程序

選取的 Agent 正在執行統一執行命令時，Terminal sessions 會列出尚未完成的終端程序。將指標停在一列上，可以查看 `Session <ID>` 和完整命令；在該列按右鍵開啟選單並選擇 **Close session**，只會關閉這個終端程序。

這和關閉 Kodex 工作階段標籤是不同動作。沒有選取 Agent 或沒有活動統一執行程序時，列表會是空的；本批不使用憑證或線上模型來製造程序，因此只保留入口說明，沒有把空列表當成程序管理示範。

## 工作階段標籤很多時

- 標籤超過可見寬度後，標籤列可以水平分頁；目前選取的標籤會被帶入視口。
- 對非目前標籤按右鍵，會針對被按右鍵的標籤開啟選單，但不會先切換目前選取項目。
- 左鍵才負責選取標籤；不要把開啟右鍵選單描述成切換工作階段。

這兩項行為已有 `SessionTabBarTest` 專項測試錨點。本批錄製集中在雙側欄，未在隔離 CLI 中建立大量標籤，因此標籤部分需要之後用真實多工作階段狀態重新錄製。
