# 工作台：会话、双侧栏与历史定位（草稿）

> 本稿是产品说明书素材，不是已确认的站点目录。界面名称和操作以真实 CLI 为准；未录到或未运行的状态不会用空面板代替。

## 先认识工作台

工作台顶部是会话标签。左右两侧是**独立的侧栏**：它们各自保存展开/收起、钉住状态和宽度，内容也可以分别选择。中间区域仍是当前会话，不会因为打开侧栏而切换会话。

新建的隔离 Home 没有选中的 Agent 时，History index 和 Terminal sessions 可能为空。这只说明当前没有可显示的数据，不代表这两项功能不可用。

## 侧栏的展开、钉住与宽度

1. 将指针移到左侧或右侧的收起按钮，侧栏会展开，让你先查看标题和内容。
2. 点击按钮即可钉住这一侧；将指针移开后，已钉住的侧栏仍保持展开。
3. 两侧分别操作：钉住左侧不会自动钉住右侧，右侧也不会改变左侧的状态。
4. 在展开侧栏与中间内容之间拖动分隔线，调整该侧宽度；松开指针后，宽度写入设置。两侧同时展开时，应用会为中间内容保留空间。

录制中的实操作是 120×36 终端：左侧从默认 28 列拖到 38 列，随后检查隔离 Home 的 `settings.yml` 中的 `sidebars.left_width: 38`。具体坐标只属于这次录制尺寸，不应写成稳定的快捷键。

## 选择侧栏内容

点击侧栏标题打开内容菜单。每一侧都可以独立选择：

- **None**：只保留侧栏标题和控制，不显示正文。
- **Terminal sessions**：显示当前选中 Agent 持有的活动终端进程。
- **History index**：显示当前选中 Agent 的稀疏历史索引时间线。

因此不要把侧栏写成固定的“会话目录”。选择 None 后，空正文是明确的配置结果；选择其他项后，是否有行还取决于当前会话状态。

## History index：预览与定位

有历史条目时：

1. 将指针停在条目上，等待预览出现。预览会读取完整条目内容；问答条目使用只读的历史表单样式。
2. 在条目上打开右键菜单，可以看到条目索引和 **Check out**。
3. 选择 **Check out** 只把当前历史阅读位置定位到该条目，然后关闭菜单；它不会回退对话、重写历史，也不会执行 Git checkout。

本批实录没有伪造历史条目。隔离空 Home 没有选中 Agent，不能安全地声称已完成预览或 Check out 的在线演示；详见 `scenes.md` 的阻塞记录。

## Terminal sessions：查看和关闭进程

选中 Agent 正在运行统一执行命令时，Terminal sessions 会列出未完成的终端进程。将指针停在一行上，可查看 `Session <ID>` 和完整命令；在该行右键打开菜单并选择 **Close session**，只关闭这一个终端进程。

这和关闭 Kodex 会话标签不是同一个动作。没有选中 Agent 或没有活动统一执行进程时，列表为空；本批不使用凭证或在线模型来制造进程，因此只保留了入口说明，没有把空列表当作进程管理演示。

## 会话标签很多时

- 标签超过可见宽度后，标签栏可以横向分页；选中的标签会被带入视口。
- 对非当前标签右键，会针对被右键的标签打开菜单，但不会先把它切换成当前标签。
- 左键才负责选择标签；不要把右键菜单的打开描述成一次会话切换。

这两项行为已有 `SessionTabBarTest` 专项测试锚点。本批录制集中在双侧栏，未在隔离 CLI 中创建大量标签，因此标签部分需要后续用真实多会话状态复录。
